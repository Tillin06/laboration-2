# GIT
## Vad är skillnaden mellan git add och git commit
Git add lägger till ändringar i staging area och git commit tar alla ändringar från staging area och sparar dessa i ens egen lokala historik.
## Varför använder man branches istället för att jobba direkt i main?
Genom att använda branches istället för att koda direkt i main underlättar man samarbete i projektet samt skyddar koden i main så att den hålls fungerande även när ändringar görs i koden.
## Vad händer rent praktiskt när man gör en merch
När man gör en merch så slår man ihop två branches till en. Har man gjort ändringar utanför main kan du man mercha dom två grenarna (branches) så kommer ändringarna hamna i main.
## Vad är skillnaden mellan att pusha till github och att publicera direkt på t.ex. Netlify?
Genom att pusha till github sparas din kod då den laddas upp samt att du kan se ändringar och historik. Netlify gör webbplatsen tillgänglig för besökare och kommer upp på internet direkt men utan historik samt att varje gång en ändring görs måste du själv ladda upp alla filer manuellt på nytt.
